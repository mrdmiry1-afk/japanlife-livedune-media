# Japan Life — японские автолоты

Использовать для ссылок `auc.jplife.ru`. Сначала подготовить и проверить карточку с текстом; в LiveDune переносить только после явного указания аккаунтов, даты и времени.

## Быстрый маршрут

1. Открыть лот и собрать год, полный заголовок модели, номер лота, кузов, комплектацию, объём, мощность, топливо, коробку, привод, пробег, оценку и фотографии.
2. Сверить модель и характеристики по Drom. Название брать из заголовка лота: поля формы могут сокращать его (`YARIS` вместо `YARIS CROSS`).
3. Нажать CARS CALCULATOR. Цена под ключ — только `ИТОГО В ГОРОДЕ ДОСТАВКИ`; не пересчитывать вручную по `Sold for`.
4. Написать текст по японскому формату: модель и год, тип поста, пять строк «Об авто», цена и «под ключ до Владивостока».
5. Проверить исходные фото. Аукционный лист, дубликаты и миниатюры не считать фотографиями машины.
6. Выбрать Figma-фрейм:
   - три фотографии машины: `пример япония` — перед, зад, салон с рулём;
   - две фотографии машины: `пример япония если всего 2 фото машины` — перед сверху, зад снизу.
7. Клонировать, а не редактировать исходный фрейм, через плагин **Japan Life Auto + Moto** (`ws://127.0.0.1:3058`, канал `gk6ustke`).
8. Экспортировать RGB JPEG 1546×2048 и открыть его в полном размере. Проверить ракурсы, название, все пять строк характеристик, цену и отсутствие обрезанного текста.

## Перед планированием LiveDune

- Сделать отдельный пост для MAX, Telegram и VK с их собственными подвалами.
- Использовать только `Asia/Vladivostok`.
- Для Telegram применить сохранённый подвал через интерфейс LiveDune: не передавать HTML как текст.
- После создания повторно проверить аккаунт, статус `scheduled`, дату, время, часовой пояс, текст, подвал, ссылки и `content_url`.
